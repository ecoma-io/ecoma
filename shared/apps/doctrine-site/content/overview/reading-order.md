# Reading order

Start with the North Star for the platform, then the specification for whichever
mechanism you came for. Each specification is self-contained on its own subject
and points to the canonical home of anything it borrows, so following a
reference is always a step toward the one place a rule is stated rather than a
paraphrase of it.

The rubric is worth reading before the specifications rather than after: it is
the set of questions each of them had to survive, and knowing the questions
makes the answers legible.

This page is the tree's first section. The remaining documents arrive with the
migration that moves them out of the working set and under the repository's
gates.
