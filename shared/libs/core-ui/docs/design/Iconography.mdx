# Iconography

Bộ icon của Alloy là **Lucide** (`@lucide/vue`) — stroke-based, điều khiển được độ dày
nét, ~1600 icon phủ đủ domain media (Film, Clapperboard, AudioLines, Scissors…), cùng hệ
sinh thái shadcn-vue mà primitives đang theo. Icon là **nét**, không phải mảng — cùng ngôn
ngữ hairline với border 1px của [Elevation](?path=/docs/design-system-elevation--docs).

## Size scale

Ba cỡ, khớp thang chữ của [Typography](?path=/docs/design-system-typography--docs) —
không chọn cỡ tuỳ hứng:

<div
  style={{
    display: "flex",
    flexDirection: "column",
    gap: "0.5rem",
    padding: "1rem 1.25rem",
    borderRadius: "0.75rem",
    border: "1px solid hsl(var(--border))",
    background: "hsl(var(--card))",
  }}
>
  {sizes.map((s) => (
    <div
      key={s.size}
      style={{ display: "flex", alignItems: "center", gap: "1rem", fontSize: "0.8125rem" }}
    >
      <code style={{ width: "3rem", color: "hsl(var(--primary))" }}>{s.size}px</code>
      <span style={{ color: "hsl(var(--foreground))" }}>{s.use}</span>
    </div>
  ))}
</div>

Dưới 14 không phải một bậc để chọn: glyph ≤ 12px chỉ xuất hiện khi **nằm trong một control**
và cỡ do hộp control quyết định — tick/dash trong ô `Checkbox` 16px và chevron của
`NumberField` ở 12px, `BrandMark` trong `TitleBar` ở 10px. Đúng vì thế mà chúng phải khai
`stroke-width` 2.5 (xem quy ước ở trên).

## Custom icon

Icon domain không có trong Lucide (brand mark, keyframe diamond…) vẽ trên **lưới 24**,
bọc `createLucideIcon`, đặt ở `shared/libs/core-ui/src/icons/` và export từ `@ecoma-io/ui`:

```ts
// shared/libs/core-ui/src/icons/BrandMark.ts
import { createLucideIcon } from "@lucide/vue";

const BrandMark = createLucideIcon("brand-mark", [
  ["rect", { x: "3", y: "3", width: "18", height: "18", rx: "4" }],
  ["path", { d: "M12 3c0 2.2-.1 3.9-.3 5.4 1.7 1.1 1.7 3.1 0 4.2.2 1.4.3 2.7.3 3.9V21" }],
  ["circle", { cx: "7.8", cy: "10.6", r: "1.3", fill: "currentColor", stroke: "none" }],
  [
    "rect",
    {
      x: "14.8",
      y: "9.3",
      width: "2.9",
      height: "2.6",
      rx: "0.8",
      fill: "currentColor",
      stroke: "none",
    },
  ],
]);
```

Kết quả nhận `size` / `strokeWidth` / `color` y hệt icon stock — nơi dùng không phân biệt
được icon custom hay Lucide.

> **Ngoại lệ có ghi nhận — `WindowControls`.** Cụm minimize/maximize/close vẽ SVG tay thay vì
> `createLucideIcon`: đây là glyph hệ điều hành (dấu trừ, ô vuông, dấu X ở tỉ lệ pixel-perfect quen mắt người
> dùng desktop), không phải icon domain — bắt chúng qua lưới 24 của Lucide sẽ lệch quy ước thị giác OS mà người
> dùng đã quen. Ngoại lệ dừng ở `WindowControls`; mọi icon domain khác vẫn bắt buộc qua `createLucideIcon`.
