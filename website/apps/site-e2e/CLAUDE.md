# site-e2e (`website/apps/site-e2e`)

Directory-scoped mechanics only — principles live in the root `CLAUDE.md`, cross-product rules in `shared/CLAUDE.md`. Nx project `site-e2e` (tags `type:e2e`, `scope:website`); its own project because e2e tests are never co-located (root `CLAUDE.md` test taxonomy). Drives the **built** site of the `site` app via `dev-cli run-e2e`; `implicitDependencies: ["site"]` — the suite would not exist without that build, and the edge is the only thing declaring it (root `CLAUDE.md` workspace-execution split).

- **This suite pins the SEO contract at the artifact level.** The shell's hreflang/canonical/`robots.txt` behavior is generated by `@nuxtjs/i18n` + `useLocaleHead` in `app.vue`; these tests read the built `dist/` HTML so a future content build cannot drift the contract without a red run.
- **What the suite covers, and the deliberate gap:** every locale serves its own `html lang`; hreflang alternates name all languages plus `x-default`; the canonical points at the production origin (`https://ecoma.io`, from the root `package.json` `homepage`) — which is correct even from a preview, where the canonical must name the production page; the switcher links home in each locale; `robots.txt` allows crawling. The preview-`noindex` half (`NUXT_PUBLIC_PREVIEW=true` → robots meta) is NOT covered here because it would need a second build of the artifact; it is checked by hand and recorded in `site/CLAUDE.md` (Rule 11 — never claim a gate covers what it does not).
- `e2e` runs through `dev-cli run-e2e` (resolves the Playwright CLI, runs under xvfb on Linux) — never call `playwright` directly, so the browser-provisioning shim stays in one place.
- The Playwright `webServer` only **serves** `vite preview` over the built `dist/` on port 4176, as a direct child with an `exec` prefix — never through an Nx target, never `pnpm exec` (single-package monorepo: no `.bin` beside this app). The build is the `e2e` target's `dependsOn`, not a step in this command. Same load-bearing reasons as `design-system-e2e`'s config; do not "tidy" them.
- A stale build is the classic false green here: `reuseExistingServer` is false and the artifact is rebuilt by `dependsOn`, so a direct `playwright test` run still serves whatever `dist/` holds — run through the Nx target.
