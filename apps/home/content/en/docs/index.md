# Ecoma Documentation

Welcome to the public documentation for **Ecoma** — the platform for building
and publishing localized public websites on `ecoma.io`.

> This documentation is a **reference/demo slice**: the pages you are reading
> are seed content written to exercise the documentation UX, information
> architecture and rendering. They describe the contracts that already exist in
> the repository, but they are **not** a complete product manual.

## How the documentation is organized

The documentation is grouped into three sections:

- [Getting Started](/en/docs/getting-started) — how to approach the docs and the
  first pieces you should read.
- [Concepts](/en/docs/concepts) — the ideas behind the platform: the public URL
  model, localization and content.
- [Guides](/en/docs/guides) — practical, task-oriented walkthroughs.

Every page is available in both English and Vietnamese. Use the language
switcher in the header to switch between `/en/docs/...` and `/vi/docs/...`
while keeping the page you are reading.

## Reading order

If you are new to the platform, read the three concepts pages before the guides:

1. [Public Web](/en/docs/concepts/public-web)
2. [Content and Locales](/en/docs/concepts/content-and-locales)
3. Then a guide such as [Local Development](/en/docs/guides/local-development)
