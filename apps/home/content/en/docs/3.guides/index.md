# Guides

The guides are practical walkthroughs. Each one completes a single task from
start to finish.

## Available guides

- [Local Development](/en/docs/guides/local-development) — start the app,
  inspect a page, change content, run tests and build.
- [Building a Public Page](/en/docs/guides/building-a-public-page) — see how a
  public page combines the app modules with content.

## How the guides are written

Every guide assumes you have already read the [Concepts](/en/docs/concepts)
section. They keep commands copy-pastable and describe the _what and why_ of
each step, not just the commands:

> Guides describe the current repository contracts. If a command no longer
> matches the repository, the repository wins.
