# Getting Started

This section explains how the documentation is structured and walks you through
your first steps with the Ecoma public web platform.

## What is in this section

- [Installation](/en/docs/getting-started/installation) — the prerequisites and
  the simplest way to run the repository locally.
- [First Steps](/en/docs/getting-started/first-steps) — a quick tour from
  opening the home page to reading a document in the docs app.

## A short reading path

The fastest path through everything:

1. Read this page.
2. Skim **Installation** to understand the workspace.
3. Follow **First Steps** once, end to end.
4. Move on to [Concepts](/en/docs/concepts) — start with
   [Public Web](/en/docs/concepts/public-web).

## How to get help

The source of truth is always the repository. If a page contradicts what the
code does, trust the code and report the discrepancy:

> The current code and configuration define current behaviour. For the public
> URLs, see the mount registry in `app/layout`; for locales, see
> `app/i18n`.
