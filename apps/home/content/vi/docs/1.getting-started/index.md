# Bắt đầu

Phần này giải thích cấu trúc tài liệu và đưa bạn qua những bước đầu tiên với
nền tảng web công khai của Ecoma.

## Có gì trong phần này

- [Cài đặt](/vi/docs/getting-started/installation) — các yêu cầu tiên quyết
  và cách đơn giản nhất để chạy repository cục bộ.
- [Các bước đầu tiên](/vi/docs/getting-started/first-steps) — tour nhanh từ
  trang chủ đến đọc một tài liệu trong ứng dụng docs.

## Đường đọc ngắn nhất

Đường nhanh nhất xuyên suốt tài liệu:

1. Đọc trang này.
2. Xem lướt **Cài đặt** để hiểu workspace.
3. Làm theo **Các bước đầu tiên** một lượt.
4. Chuyển sang [Khái niệm](/vi/docs/concepts) — bắt đầu với
   [Web công khai](/vi/docs/concepts/public-web).

## Cách tìm trợ giúp

Nguồn chân lý luôn là repository. Nếu một trang mâu thuẫn với code hiện tại,
hãy tin code và báo lại sai lệch.
