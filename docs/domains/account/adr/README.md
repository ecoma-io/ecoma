# Account — ADR index

Architectural decision record (ADR) của bounded context **Account** (xem [`../README.md`](../README.md)). Mỗi quyết định có **một** canonical location là ADR tương ứng; nhìn lại một quyết định hay đảo nó phải qua ADR mới (không sửa ADR đã Accepted để đổi ý một cách âm thầm) — trừ cập nhật chính tả hay cross-reference không đổi nghĩa.
