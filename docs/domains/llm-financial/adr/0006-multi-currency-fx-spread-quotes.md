# ADR-0006 — Multi-currency, Vietcombank FX reference rates, spread, immutable quotes

Status: Accepted (legal gates OPEN).

Context: Initial currencies VND, USD, CNY; extensible currency registry.

Decision: Currency vocabulary: preferred_currency, display_currency, deposit_currency, payout_currency, ledger_currency (VND). Không ambiguous account_currency. Display: Vietnam visitors default VND; others dùng configured country-to-currency mapping fallback USD; multi-currency price display nơi supported; tách display preferences khỏi legal-market policy. FX source: Vietcombank reference rate (không guaranteed executed bank rate). Preserve buying cash / buying transfer / selling distinction: foreign-currency deposit (Ecoma receives foreign currency, convert sang VND) dùng buying-transfer rate; foreign-currency payout (Ecoma dùng VND để mua foreign currency) dùng selling rate. 1% spread trên foreign-currency deposits và payouts; không spread trên VND; spread không presented như separate fee; Ecoma bears FX execution risk; avoid double charging. Candidate formulas: foreign deposit VND credit = foreign amount × VCB buying-transfer rate × 0.99; foreign payout foreign amount = VND amount ÷ VCB selling rate × 0.99. Document exact rounding/precision/direction/snapshot semantics. FX observation append-only: provider, base/quote, rate type, value, provider publication timestamp, fetch timestamp, validation timestamp, version, raw payload hash/provenance, validation status. Distinguish publication vs fetch time; newly fetched stale rate vẫn stale; Vietcombank có thể không publish mỗi 5 phút, define max source-staleness; invalid/stale rates fail closed cho new quotes; manual overrides yêu cầu actor, reason, before/after, audit. Payout quote: server hard expiry max 5 phút từ creation; client confirmation window 2 phút (UX only); server clock authoritative; immutable quote snapshot (amount, currency, FX rate+direction, spread policy/version, rounding policy, beneficiary snapshot/reference, creation/expiry/confirmation time, status); khi confirmation re-check expiry/status, seller/tenant status, authorization, holds, available EC, idempotency, beneficiary validity; expired quote không silently edited/extended; tạo new quote + seller reconfirm. Explicit manual-disbursement deadline sau confirmation; beyond approved validity window yêu cầu new quote + seller reconfirm. Model listing price conversion: seller set base model price; system generate converted prices cho supported currencies; seller có thể override individual currency prices; FX refresh chỉ update auto-converted prices, never overwrites seller overrides; versioned pricing và immutable price snapshots cho admitted requests; không apply deposit/payout FX spread vào public model price conversion trừ khi có decision rõ ràng.

OPEN: legal restrictions là approval gates; actual bank settlement flow có thể revise formulas.
