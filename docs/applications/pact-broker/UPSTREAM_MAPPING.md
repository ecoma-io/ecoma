# UPSTREAM_MAPPING — `pact-broker-workers` → Ecoma Pact Broker

Nguồn: `bison-digital/pact-broker-workers` v3.0.0 (HEAD `a525725`, clone tại `/tmp/pact-broker-workers`).
Đích: `apps/pact-broker-api` + `apps/pact-broker-app` trong repo này.

Quy tắc đọc bảng: **"Port"** = tái sử dụng logic có điều chỉnh; **"Viết mới"** = không có tương đương upstream; **"Cấm sao chép"** = hành vi upstream cố tình không mang sang.

## 1. Tổng quan kiến trúc upstream vs đích

| Khía cạnh       | Upstream                                         | Ecoma đích                                             |
| --------------- | ------------------------------------------------ | ------------------------------------------------------ |
| Runtime         | Cloudflare Worker + Durable Object               | Cloudflare Worker (không DO)                           |
| Storage         | SQLite trong DO (singleton)                      | PostgreSQL qua Hyperdrive (`db-pact-broker`)           |
| ORM             | Drizzle `drizzle-orm/sqlite-core`                | Drizzle `drizzle-orm/pg-core`                          |
| Migrations      | Raw SQL array chạy trong DO constructor          | File SQL idempotent, apply từ CI runner, advisory lock |
| Auth            | Shared `PACT_BROKER_TOKEN` + `ALLOW_PUBLIC_READ` | Machine token per-tenant hash-only + OIDC dashboard    |
| Tenant          | Không có                                         | Tenant isolation DB-level composite FK/unique          |
| Logic trung tâm | `PactBrokerDO` 1494 dòng (mọi thứ trong 1 class) | Tách domain service + repository (PG) + route          |

## 3. Hợp đồng ẩn của Pact CLI (bắt buộc giữ)

1. Index HAL khai `compatibility: { version: "2.107.0" }` — CLI ≥ 2.86 gate tính năng.
2. `pb:publish-contracts` trên index — có link thì CLI mới dùng `publish --branch` batch endpoint.
3. `pb:pacticipant-branch-version` — PUT `{}` từ pact-reference (branch-version PUT body bị ignore).
4. `pb:provider-pacts-for-verification` + href form `?consumer=X&tag=Y` — CLI follow link này.
5. Record-deployment HAL links mang `name` per-environment — CLI match theo name.
6. Publish response 201 (mới) / 200 (đã có, unchanged/changed) theo SHA.
7. `can-i-deploy` exit code: fail khi `deployable === false` **hoặc** `null`.

## 4. Deviation có chủ đích so với upstream

`can-i-deploy` khi matrix rỗng: upstream để đi qua `summarizeMatrix([])` → trả
`deployable: true` kèm "There are no missing dependencies" (fail-open). Hai tình huống
rỗng đều bị nhánh này che: (1) selector không khớp version/pacticipant nào — version gõ
sai vẫn thấy xanh; (2) version tồn tại nhưng chưa publish pact nào — version chưa từng
được contract-test vẫn thấy xanh. Ecoma ép fail-closed cả hai:
`deployable: null`, counts `unknown: 1`, reason tường minh phân biệt hai tình huống
("There is no version X of Y…" / "Version X of Y exists but has no pacts published…").
CLI exit code vẫn fail ở cả `false` lẫn `null` (mục 3.7), nên hợp đồng CLI không đổi;
chỉ bỏ nhánh "unknown → green". Bắt nguồn từ §6 `01-architecture.md`: unknown không bao
giờ là safe.

## 5. Quyết định không mang sang (kèm lý do)

| Hành vi upstream                                      | Lý do từ chối                                                                          |
| ----------------------------------------------------- | -------------------------------------------------------------------------------------- |
| Shared `PACT_BROKER_TOKEN` cho mọi caller             | Không multi-tenant được; leak một token = mất hết (SR-001).                            |
| `ALLOW_PUBLIC_READ` mặc định đọc công khai            | Pact nội bộ Ecoma; SR-003.                                                             |
| CORS `*` mặc định                                     | SR-005.                                                                                |
| SQLite trong DO + migration trong constructor         | Không còn DO; HD6 cấm DDL từ Worker.                                                   |
| Webhook fire qua `waitUntil` + retry [200,800,3200]ms | SR-006: tắt outbound tới khi có SSRF guard; retry schedule chỉ giữ trong code khi bật. |
| Badge public                                          | SR-003; non-goal.                                                                      |
| Rate limit per-IP qua DO/KV                           | Không có KV binding trong phạm vi; non-goal ghi rõ.                                    |
